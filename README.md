# VirtuoPet

## Setup

Make sure [Node.js](https://nodejs.org/en/download) is up-to-date

Also install pnpm v9 using:
```bash
npm install -g pnpm@9
```

Switch to the client directory, and install the node modules using:
```bash
pnpm install
```

On your phone, install Expo Go v54 from the App store or Play store

To run the app, run:
```bash
pnpm expo start
```
